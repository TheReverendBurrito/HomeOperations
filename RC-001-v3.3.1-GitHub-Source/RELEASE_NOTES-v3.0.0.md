# RC-001 v3.0.0 Production Release

RC-001 v3.0.0 promotes the validated Networking implementation to production and freezes it alongside the rest of the application.

## Production scope

- Home
- Environment
- Security
- Lighting
- Networking
- Operations

## Networking production features

- Network Health displayed before Logical Network Topology
- Collapsible Topology, Infrastructure, Security Devices, Client Devices, and Device Inventory sections
- Device discovery and classification
- Search, filters, sorting, and registry overrides
- Device Details drawer
- Live status animations
- Reduced-motion accessibility

## Release policy

The v3.0.0 source is frozen. Future modifications must be delivered as a new versioned release.
